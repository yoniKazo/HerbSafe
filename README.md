# בסיס ידע התחלתי ל-RAG — אינטראקציות (seed)

קובץ `interactions-rag-seed.jsonl` הוא seed דו-לשוני (עברית + אנגלית) בפורמט **JSONL** (רשומה אחת לכל שורה), מוכן לבליעה למנוע RAG.

## ⚠️ אזהרה קריטית — קרא לפני שימוש

התוכן הקליני כאן הוא **דוגמאות ידועות ומבוססות ברמת ספר-לימוד בלבד**, שנועדו לתת לך מבנה עובד להתחיל לפתח עליו. כל רשומה מסומנת:

```
"verification_status": "unverified_seed"
```

לפני העלאה ל-production **חובה**:
1. לאמת או להחליף כל רשומה מול מקור סמכותי (ראה רשימת הורדה למטה), ולעדכן את שדה `source` ואת `last_reviewed`.
2. להעביר את הניסוח הקליני בעברית בדיקה של איש מקצוע — התרגום כאן נועד לאחזור ולתצוגה, לא כסמכות קלינית.
3. לא לשלוח את הקובץ כמו שהוא למשתמשי קצה.

## סכמה (שדות)

| שדה | תיאור |
|------|-------|
| `id` | מזהה ייחודי לרשומה |
| `type` | סוג האינטראקציה: `herb_drug_interaction` / `drug_food_interaction` / `supplement_drug_interaction` |
| `subject` / `object` | שני צדי האינטראקציה. כל אחד עם `kind`, `canonical` (מזהה יציב), `name_en`, `name_he`, ולעיתים `latin` |
| `severity` | `major` / `moderate` / `minor` |
| `effect_en` / `effect_he` | תיאור ההשפעה |
| `recommendation_en` / `recommendation_he` | ההמלצה המעשית |
| `text_en` / `text_he` | ה-chunk השלם לאחזור — זה מה שמטמיעים (embedding) |
| `source` | מקור הרשומה (כרגע placeholder — למלא באימות) |
| `verification_status` | `unverified_seed` עד לאימות |
| `last_reviewed` | תאריך אימות אחרון (null עד לאימות) |

## איך להשתמש ב-RAG

- **הטמע את `text_en` ואת `text_he` בנפרד** (שני וקטורים לכל רשומה, או שתי רשומות במאגר הווקטורי). כך שאילתה בעברית תשלוף את הטקסט העברי, ושאילתה באנגלית את האנגלי.
- **שמור את השדות המובנים כ-metadata** (`subject.canonical`, `object.canonical`, `severity`, `type`). אלה מאפשרים לסוכן הבטיחות לבצע **lookup דטרמיניסטי** — לא רק retrieval סמנטי — ולתעדף `major` ומקורות מאומתים על פני seed.
- שקול שדה `provenance`/דירוג אמון לכל רשומה, כדי שסוכן הבטיחות יעדיף מקור סמכותי על פני seed לא מאומת.

## מה להוריד בהמשך (מתועדף)

1. **DDInter** — עמוד השדרה של תרופה-תרופה, מובנה ואקדמי.
2. **מקורות NIH/NLM ברשות הכלל** — לצד הצמחים/תוספים: MedlinePlus, NCCIH, וה-DSLD (עם API). ברשות הכלל → מותר גם מסחרית.
3. **Drug-Food (Kaggle)** — seed לסוכן התזונה, לאימות מול הנ"ל.
4. **MSK About Herbs** — reference בלבד (לקרוא ולאמת ידנית), לא לבליעה אוטומטית (תוכן מוגן בזכויות יוצרים).
